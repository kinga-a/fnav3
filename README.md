# EdgeOne KV TOTP 数据管理应用  基于 EdgeOne Makers 平台的全栈应用，使用 KV 存储数据，支持账号密码 + TOTP 双因素认证。  ## 项目结构  ```  edgeone-kv-totp-app/  ├── index.html              # 前端管理界面  ├── edgeone.json            # EdgeOne Makers 项目配置  ├── package.json            # 依赖配置  ├── README.md               # 本文件  └── functions/              # Edge Functions      └── api/                  # API 路由          ├── [[path]].js       # 主路由（Hono 框架）          ├── auth.js           # 密码哈希 + JWT Token          ├── totp.js           # TOTP 生成与验证          ├── kv.js             # KV 存储封装          └── utils.js          # 工具函数  ```  ## 功能特性  - **KV 数据管理**：增删改查、前缀搜索、批量操作  - **双因素认证**：账号密码 + TOTP（兼容 Google Authenticator）  - **JWT 会话**：Token 过期自动失效  - **安全存储**：PBKDF2-SHA256 密码哈希  - **纯前端界面**：无需构建步骤，直接部署  ## 快速开始  ### 1. 生成密码哈希和 TOTP Secret  运行以下脚本（需要 Node.js 20+）：  ```bash  node setup.js  ```  或手动执行：  ```javascript  // 在浏览器控制台或 Node.js 中运行  // 生成密码哈希  const encoder = new TextEncoder();  const password = 'your-password';  const salt = crypto.getRandomValues(new Uint8Array(16));  const saltHex = Array.from(salt).map(b => b.toString(16).padStart(2,'0')).join('');  const key = await crypto.subtle.importKey('raw', encoder.encode(password), 'PBKDF2', false, ['deriveBits']);  const bits = await crypto.subtle.deriveBits({name:'PBKDF2', salt:encoder.encode(saltHex), iterations:100000, hash:'SHA-256'}, key, 256);  const hash = Array.from(new Uint8Array(bits)).map(b => b.toString(16).padStart(2,'0')).join('');  console.log('PASSWORD_HASH:', `${saltHex}$100000$${hash}`);    // 生成 TOTP Secret（32 位 Base32）  const chars = 'ABCDEFGHIJKLMNOPQRSTUVWXYZ234567';  const secret = Array.from(crypto.getRandomValues(new Uint8Array(32))).map(b => chars[b % 32]).join('');  console.log('TOTP_SECRET:', secret);  ```  ### 2. 部署到 EdgeOne Makers  1. 登录 [EdgeOne Makers 控制台](https://pages.edgeone.ai)  2. 创建项目，导入本仓库  3. 在 **KV Storage** 中：     - 申请开通 KV 服务     - 创建 Namespace（如 `kv-app-data`）     - 绑定到项目，变量名设为 `MY_KV`  4. 在 **环境变量** 中配置：     | 变量名 | 说明 |     |--------|------|     | `ADMIN_USERNAME` | 管理员用户名 |     | `ADMIN_PASSWORD_HASH` | PBKDF2 哈希密码 |     | `TOTP_SECRET` | Base32 TOTP 密钥 |     | `JWT_SECRET` | JWT 签名密钥 |     | `MY_KV` | KV 绑定变量名 |  5. 点击部署  ### 3. 配置 TOTP  1. 使用 Google Authenticator、Microsoft Authenticator 或类似应用  2. 手动输入 TOTP Secret 或扫描 QR 码（可通过 `/api/auth/totp-setup` 获取 URI）  3. 登录时输入 6 位动态验证码  ## API 端点  | 方法 | 路径 | 说明 | 认证 |  |------|------|------|------|  | POST | `/api/auth/login` | 账号密码登录 | 否 |  | POST | `/api/auth/verify-totp` | TOTP 验证 | 否 |  | GET | `/api/auth/verify` | 验证 Token | Bearer |  | GET | `/api/kv` | 列出所有键 | Bearer |  | GET | `/api/kv/:key` | 获取单个值 | Bearer |  | PUT | `/api/kv/:key` | 创建/更新 | Bearer |  | DELETE | `/api/kv/:key` | 删除 | Bearer |  | POST | `/api/kv/batch` | 批量操作 | Bearer |  ## 安全说明  - 密码使用 PBKDF2-SHA256 + 随机盐 + 10 万次迭代  - TOTP 基于 RFC 6238，30 秒时间窗口，支持 ±1 步容差  - JWT Token 1 小时过期，存储在浏览器 localStorage  - 所有 KV 操作必须通过 Bearer Token 认证  - 建议启用 HTTPS 并配置安全响应头  ## 许可证  MIT
